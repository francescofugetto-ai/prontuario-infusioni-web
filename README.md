# Prontuario delle infusioni in UTIC

**https://francescofugetto-ai.github.io/prontuario-infusioni-web/**

Questo repository contiene soltanto il documento consegnato del prontuario delle
infusioni in terapia intensiva cardiologica — versione 2.3.3 — servito da
GitHub Pages. Esiste per l'iPhone: li' un file HTML salvato sul telefono si apre
nell'anteprima, che non esegue il motore di calcolo, mentre da questo indirizzo,
in Safari, il tool funziona, si aggiunge alla schermata Home e dopo la prima
apertura funziona anche senza rete.

Sorgente, dati e verifiche stanno in un repository privato, e questo si aggiorna
solo da li', dopo che le verifiche sono passate. **Non modificare i file qui**:
la pubblicazione successiva li sovrascrive.

Materiale di consultazione: non sostituisce il giudizio clinico, i protocolli di
reparto ne' le linee guida. Diluizioni e concentrazioni vanno verificate sul
protocollo del proprio reparto.

Creato dal dott. Francesco Fugetto.
